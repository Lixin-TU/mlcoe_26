# Particle Flow Filter (PFF) Implementation

```run PFF.py``` to generate PFF_results.npz
#### Step2: 
```run diag_particle_distribution.py``` to visualize particle distribution

```run PFF_scalar.py``` to generate PFF_scalar_results.npz

```run diag_particle_distribution_scalar.py``` to visualize particle distribution for scalar kernel
